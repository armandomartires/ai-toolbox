# .ai/ — Plan · Develop · Test · Validate Conventions

Entry point of the governance layer (ADR-0066). Live files hold state, not
history (ADR-0033); their line budgets are gated. This repository tracks its
work in these files: `tracker.conf` says `files` (ADR-0037).

## Directory map

```
.ai/
├── 00.CONVENTIONS.md   this file
├── 10.CURRENT_STATE.md what is true now (≤200 lines)
├── 20.PLAN.md          the open sprint, right now (≤80 lines)
├── 30.ROADMAP.md       phases, the S###_Name sprint table, risks
├── 35.AD_HOC_TASKS.md  "found this, not fixing now" (was planning/BACKLOG.md)
├── 40.RISK_REGISTER.md rated risks + Last reviewed date
├── GOALS.md            the Compass board, kept in step with the briefs
├── id-map.tsv          old id → new id, old path → new path
├── decisions/          ADR-NNNN-short-title.md
├── tasks/              S###.T###_PascalName.md, one brief per task
├── reviews/            S###-checkpoint.md, else YYYY-MM-DD-slug.md
├── sessions/           SESSION-*.md and INDEX.md: short records
└── archive/            retired plans/ and sprints/, read-only
```

`PROJECT_MAP` and `GLOSSARY` are in `docs/`; the tier and turn tables in
`docs/development/`. Templates are project-workflow's
(`skills/project-workflow/templates/`); there is no `tasks/TODO.md`: the
briefs and `GOALS.md` are the list.

## Ids

- **Task** `S###.T###`: its sprint, then the next free T number in it.
  Branch `agent/S###.T###`; `scripts/worktree.sh add S###.T###`.
- **Commit subject** `<Imperative summary> (S###.T###)`; no hash in the brief.
- **ADR** `ADR-NNNN`, in the H1, in prose and in the file name; the next is
  the next free number.
- **Sprint** `S###_Name` in `30.ROADMAP.md`. S001–S011 are the old S1–S11,
  S012–S016 the Post-S4, -S5, -S8, -S9 and -S10 buckets, S017 the convention.
- **Old ids** (`TASK-NNNN`, `REVIEW-NNNN`, `0013-x.md`) stay as written in
  history: closed briefs, ADRs, reviews, sessions, commits. They resolve
  through `id-map.tsv`, which the gate checks; live files use the new ids.

## Briefs

New briefs follow project-workflow's task template, with a required
`## Acceptance criteria` and the statuses `review` and `cancelled`; briefs
written before the switch keep their legacy schema (ADR-0066 clause 4).

## Closing an ad-hoc entry

An entry in `35.AD_HOC_TASKS.md` is `### NNN. Title` (a `B-NNN` row kept its
number). To close one, move it under `## Resolved`; its *Ready when* line reads
*Closed <date> by `S###.T###`* (or an `ADR-` or review id). That artifact must
exist, and a task must read `done` or `cancelled`. Update the "N items are
open" sentence in the same commit. At most three open entries are titled
*Unexercised:* (ADR-0039). `scripts/check-backlog-closures.py` checks all of
it (B-038, B-047).

Process, statuses and the definition of done are in `AGENTS.md`.
