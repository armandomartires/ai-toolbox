## Objective

A person on the desktop app can set a mod's colours by hand. Each mod's command takes `theme dark|light|auto`
(`/agent-watch theme light`, `/compass theme light`, `/switchboard theme light`, `/orchestrate theme light`).
`dark` and `light` pin Night ops or Daylight; `auto` returns to following Claude Code's `theme` setting
(`ADR-0043` clause 1). The choice is kept in the mod's own `$.store`, so it survives a restart, and the
pane redraws at once. A pinned theme is not overridden by a later `config.set` of `theme`.
