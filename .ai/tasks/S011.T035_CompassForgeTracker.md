## Goal

task-compass never reads `tracker.conf`. On a GitLab or GitHub tracker (ADR-0037) the roadmap is gone, so the pane falls back to an empty board and invites `/goals init`, which writes the `.ai/GOALS.md` copy that project-workflow's `tracker.md` forbids. The mod will honour the declaration: on a forge it shows the kept state file `20.PLAN.md` read-only and writes nothing. Found by the 2026-11-20 alignment audit of the mod against project-workflow 7.2.0 (`S011.T034`).

3. Copy it byte-identical to `claude/hooks/`, `opencode/` and `codex/scripts/` (rule 10). Name no fixture `tracker.ts`.
4. 5. `view.tsx`: a resizable `Plan` panel (rule 9) with the forge, its path and the card rows; no carousel, no legend; a missing `20.PLAN.md` or an invalid conf is said in the pane.
