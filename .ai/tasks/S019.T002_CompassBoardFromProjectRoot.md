# S019.T002_CompassBoardFromProjectRoot

**Status**: review

## Goal

task-compass 0.12.6 finds the board from the project root, not from the shell's folder. On 2026-11-15, during the live probe of `S011.T006`, the `story` tool was called while the session's shell stood in `<repo>/.ai/`. It wrote `<repo>/.ai/.ai/GOALS.md` and left the real board unchanged. The Claude plugin read `$.session.cwd()`, which follows a shell `cd`. It took `<repo>/.ai/GOALS.md` for a root `GOALS.md` and copied it under a new `.ai/`.

## Inputs

| Artifact | Expected state |
|---|---|
| `mods/task-compass/claude/hooks/register.tsx` | `loadGoals` resolves the board from `$.session.cwd()` |
| `mods/task-compass/core/board.ts` and its three copies | no path logic |
| `mods/task-compass/codex/scripts/`, `opencode/compass.ts` | read `<folder>/.ai/GOALS.md` of the folder they are given |

## Plan

1. Red test in the Claude plugin: the session's root is `/p` and its shell stands in `/p/.ai`, and the story tool writes `/p/.ai/GOALS.md` and nothing under `/p/.ai/.ai`.
2. `core/board.ts`: `foldersUp` and `projectFolder`. Walking up, `projectFolder` takes the nearest folder with a board. It never resolves to a folder inside a `.ai/`. Copy `board.ts` to the three harness folders.
3. Claude: `loadGoals` starts from `$.session.root()`, then `projectFolder` over the layout's markers.
4. Codex and OpenCode: `runStory`, `sessionStart` and `sidebarBoard` resolve their folder through `projectFolder`.
5. Version 0.12.6, README *Not yet verified*, `10.CURRENT_STATE.md`.

## Status notes

- The task asked for a CHANGELOG entry. `docs/development/mod-workflow.md` stage 8 says mods keep no `CHANGELOG.md`: `git log --oneline -- mods/<name>` is the changelog (ADR-0033). The change is recorded in the README's *Not yet verified* entry and in the commit.
- Behaviour change beyond the bug: a session root with no board now uses the nearest board above it, up to the repository's top (a folder holding `.git`). Before, it showed an empty board.
- Not covered: a `.ai-layout.json` naming a custom root (say `planning/`) with the session's root inside that folder. `boardFolders` skips only folders named `.ai`, so `planning/` would still count as its own project. The default layout, the case seen, is covered.
