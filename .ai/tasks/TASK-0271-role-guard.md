## Execution plan

1. Write one fixture per refused term: the forbidden call is denied or asked, the allowed call passes. Run them against Claude Code with no guard and record which terms the harness already holds.
2. Write `role-guard.py` and the generated `role-guard.json`; rely on TASK-0276's permission rules for force-push and push, because hook `if` matching is best-effort; if that task has not landed, the fixtures for those rules wait for it.
3. Run the fixtures green for each passing term; remove the hook or the rule and see that term's fixture fail.
4. Extend `emit-agents.py` to map the passing terms, add `claude-code` to the passing roles' `clients:` lists, and rebuild the agents plugin so it carries them.
5. Add the ask-then-deny switch with the date the two weeks end, and record it in the ADR.
6. Write the ADR superseding clause 8.3 for the passing terms only; update `docs/registry.md`.
7. Run `tests/validate.sh`.
