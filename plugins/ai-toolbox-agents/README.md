# ai-toolbox-agents

Role agents emitted for Claude Code by scripts/emit-agents.py. Generated by scripts/build-plugin.py; edit agents/ in the repository and rebuild. It depends on ai-toolbox-skills. It ships no hooks: the worktree hooks are this repo's sibling-worktree rule and come from scripts/install.sh (a consumer repo has no scripts/worktree.sh, and they would run twice). It ships no permission rules: a plugin settings.json is not a known way to ship them, so scripts/install.sh writes them. Known gaps from the plugin cache: skills and agents were written for an ai-toolbox checkout. unattended-ops, design-flow and ansible-ops point at loops/ (not shipped); the emitted agents cite skills/... paths that resolve only in a checkout; unattended-ops/scripts/check-binding.sh defaults to ../../../loops/unattended-run/loop.md and needs the loop file passed as its second argument. mod-dev is left out (checkout only).
