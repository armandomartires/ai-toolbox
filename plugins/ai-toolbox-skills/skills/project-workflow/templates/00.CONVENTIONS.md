# .ai/ — Plan · Develop · Test · Validate Conventions

**Size budget**: ≤3072 bytes, read every session. Detail lives in
`reference/` (exempt, like `tasks`/`decisions`/`reviews`).

## The governing rule

> **`.ai/` holds *why* and *what's next*.**
> **`AGENTS.md` + `docs/` hold *what is*.**
> **Git holds *what changed*.**

Every artifact has one owner — link, never copy.

## Directory map

```
.ai/
├── 00.CONVENTIONS.md   this file
├── 20.PLAN.md          what's in flight, right now
├── 30.ROADMAP.md       sprint history + what's next + deferred
├── 35.AD_HOC_TASKS.md  "found this, not fixing now"
├── decisions/          ADRs — one per hard-to-reverse call
├── tasks/              one brief per unit of work, sprint-prefixed
├── reviews/            periodic checkpoints
└── reference/          on-demand detail (table below)
```

Layout: `.ai-layout.json` (`reference/layout-declaration.md`).
Tracker: `tracker.conf`, default `files`; on `gitlab`/`github` the forge
holds 20/30/35, `tasks/`, `reviews/` (`reference/tracker.md`).

## The loop

| Phase | Owned by |
|---|---|
| **Plan** | `tasks/S###.T###_Name.md` (Goal + Plan) |
| **Develop** | code + commit messages |
| **Test** | `tasks/…` (Verification) + real suite |
| **Validate** | `tasks/…` (fails-when-reverted) + `reviews/` |

## When to write what

| Situation | Write |
|---|---|
| Real work (feature, fix, refactor) | `tasks/S###.T###_Name.md` (scheme: `reference/task-lifecycle.md`) |
| Expensive-to-reverse call | `decisions/NNNN-short-title.md` (ADR) |
| Noticed something, out of scope now | Bullet in `35.AD_HOC_TASKS.md` |
| A sprint ends | `reviews/S###-checkpoint.md` |
| Trivial (typo, config tweak) | Just commit it |

Reasoning the diff doesn't show belongs in `.ai/`.

## Definition of Done

1. **Full test suite passes.**
2. **A test fails when reverted**: stash, see it fail, restore.
3. **Docs updated in the same unit of work.**
4. **Working tree clean.**
5. **The task (file or issue) is current**: Status, deviations. The
   commit subject names it; no hash in it.
6. **A failed push means not done**; end with the task report
   (`reference/git-workflow.md`).

## Reference (load on demand, not every session)

| File | Read when... |
|---|---|
| `reference/session-handover.md` | starting, ending or handing off |
| `reference/layout-declaration.md` | scaffolding, or layout isn't `.ai/` |
| `reference/tracker.md` | tracker isn't `files` |
| `reference/size-budgets.md` | editing a live file |
| `reference/task-lifecycle.md` | creating/promoting a task |
| `reference/git-workflow.md` | pushing, or writing a task's Status |
| `reference/environments-and-secrets.md` | touching a secret/env var |
| `reference/skill-maintenance.md` | improving the skill itself |

## Relationship to other docs

- **`AGENTS.md`** — mandatory rules; an ADR changing one updates it in
  the same commit.
- **`docs/*.md`** — reference docs; `.ai/` links, never copies.
- **Git log** — *what* changed; never a changelog.
