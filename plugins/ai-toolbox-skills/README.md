# ai-toolbox-skills

Skills from the ai-toolbox repository, one folder per skill under skills/. Generated by scripts/build-plugin.py; edit the repository's skills/ and rebuild, never this copy. Known gaps from the plugin cache: skills and agents were written for an ai-toolbox checkout. unattended-ops, design-flow and ansible-ops point at loops/ (not shipped); the emitted agents cite skills/... paths that resolve only in a checkout; unattended-ops/scripts/check-binding.sh defaults to ../../../loops/unattended-run/loop.md and needs the loop file passed as its second argument. mod-dev is left out (checkout only). The five run-<loop> skills (invoked by hand, never by the model) carry their loop.md beside them, so they work without loops/; the other loops/ pointers in the skills still do not resolve here.
