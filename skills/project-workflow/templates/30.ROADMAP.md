# Roadmap

Sprint history, what's next, and — the more valuable half of this file —
decisions **explicitly deferred**, with the reason, so they don't get
silently relitigated.

**Size budget**: each sprint-history row is an index, not a digest —
state the theme in a sentence or two and link to the checkpoint/task
briefs rather than restating their content (see `reference/size-budgets.md`).
"Explicitly deferred" is exempt.

no prior history yet, start with a single row for the current sprint.
