# Active Plan (forge tracker)

Where the project stands, right now, for the session that starts cold.
Tasks are issues and the board holds them: this file carries **no task
list**. It is state, not history (git owns that).

**Size budget**: the same as the files-tracker `20.PLAN.md` — keep it small
(`reference/size-budgets.md`). Edit the state it describes; never append a
narrative.

Last updated: YYYY-MM-DD.

## Current state

Two or three lines: what the project is doing now and what works today.

## Open milestone and board

- Milestone: `S###_SprintName` — one sentence on its purpose.
- Board: name of the issue board (GitLab) or Project (GitHub). Name them;
  never paste a URL or host.

## Blocked

What is blocked and on which issue (`group/name#N`). "Nothing currently
blocked" if true — say so rather than leaving this empty.

## Next action

One line: the issue to take next, taken from the board.

## History

Only if the repository moved to this forge: one line naming the tag that
holds the old planning files and how to read them. Delete this section
otherwise.
