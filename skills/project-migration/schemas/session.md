what this session did, field by field
!standard
A record of one working session, written as it ends. Fill every field; a
blank field and a field answered "none" mean different things.
!explicit
Fill every field below as the session ends, not from memory later. Under
"Commands and validations" paste what the commands printed rather than
summarising. A blank field and a field answered "none" mean different
things, so answer all of them.
!literal
Fill in every field below before the session ends. Do not fill them in from
memory in a later session.
  Date                     — YYYY-MM-DD.
  Agent/model              — which model and client did the work.
  Objective                — what you set out to do, in one sentence.
  Context consulted        — which files you read first.
  Tasks worked on          — the task IDs.
  Decisions                — anything decided that a later session must know.
  Commands and validations — the commands you ran and what they PRINTED.
  Problems                 — what went wrong, including anything unresolved.
  Commit/push              — the commit hash, and whether the push succeeded.
  Next action              — the one thing the next session should do first.
Answer every field. If a field genuinely does not apply, write "none" --
leaving it blank means nobody decided. Delete this comment when done.
