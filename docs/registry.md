# Component Registry

GENERATED by scripts/sync-registry.sh — do not hand-edit.

## Install the mods (Claude Code)

The repo root is a Claude Code marketplace (`.claude-plugin/marketplace.json`) listing the mods below:

```
/plugin marketplace add https://<gitlab-host>/<group>/ai-toolbox.git
/plugin install <mod>@ai-toolbox
```

`install.sh` is for development and non-Claude ports. The claude.ai organization library is the second release target for the same mods.
